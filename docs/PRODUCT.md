# PRODUCT — work-service

> Статус: согласовано 2026-10-18. Источник: `brief.md` + ответы владельца. Изменения — только через обсуждение и обновление этого файла.

## 1. Цель

Сервис, который помогает искать работу в Германии:
1. находит подходящие вакансии в источниках, которые выбрал пользователь;
2. оценивает шанс и показывает совпадения и пробелы относительно резюме;
3. пишет мотивационное письмо и **мягко** адаптирует Lebenslauf под вакансию (только правда);
4. пользователь откликается одним нажатием — в боте или на сайте.

**Универсальность.** Сервис не привязан к IT: профессия, навыки, опыт и желаемые роли берутся из Lebenslauf пользователя (повар, медсестра, логист, разработчик — неважно). Чего нет в резюме — сервис спрашивает, а не додумывает.

**Стадия.** Pet-проект, единственный пользователь — владелец. Архитектура с первого дня multi-user (аккаунты, изоляция данных, согласия), чтобы позже открыть сервис другим по подписке ~5–10 €/мес.

## 2. Пользователи

| Роль | Описание |
|---|---|
| **Owner** | Владелец сервиса. Единственный, чьи запросы к LLM идут через подписку Claude Pro. |
| **User** (позже) | Соискатель любой профессии в Германии. LLM — только через API-провайдер, оплачивается подпиской. |
| **Admin** | Технические уведомления: сломался источник, лимит LLM, истёк токен. Сейчас = Owner. |

## 3. Языки

- **Письмо и адаптированное резюме** — на языке вакансии (DE или EN), с ручным override.
- **UI сайта и бота** — i18n с самого начала (DE / EN / RU / UA), язык выбирает пользователь.
- **Документация** — русский, термины на английском. **Код** — английский.

## 4. MVP

### 4.1 Аккаунт и профиль
- Регистрация (email + пароль), согласие на обработку данных (версионированное), привязка Telegram через deep-link из бота.
- Загрузка Lebenslauf (PDF / DOCX) и доп. данных (сертификаты, языки, водительские права, готовность к переезду и т.п.).
- Разбор резюме в **структурированный профиль** (опыт, образование, навыки, языки, локация, желаемые роли). Профиль всегда редактируется вручную.
- **Пробелы в профиле** → вопросы пользователю в боте / на сайте; ответ сохраняется в профиль как факт.

### 4.2 Поиск: настройки
- Желаемые роли / ключевые слова, слова-исключения.
- **Локация + радиус** (км) и/или remote.
- Языки вакансий, минимальная зарплата, тип занятости.

### 4.3 Источники вакансий
- **Ручная вставка** ссылки или текста вакансии (бот и сайт).
- **Telegram-каналы**, которые пользователь добавляет сам (публичные). Сервис предлагает стартовый список.
- **Сайты вакансий** с поиском по региону и радиусу: Bundesagentur für Arbeit (первым), StepStone, Indeed, далее — расширяемо (Arbeitnow, Adzuna, meinestadt.de, Stellenanzeigen.de, kimeta и др.). Каждый сайт — отдельный плагин.
- Сервис сканирует источники **по расписанию, без агрессивного опроса**.

### 4.4 Фильтрация (без LLM)
Дешёвый префильтр перед любым вызовом нейросети: ключевые слова, исключения, язык текста, расстояние до локации, зарплата, дубликаты.
**Нет данных в вакансии** (зарплата, локация и т.п.) → вакансия **не отсекается**, поле помечается «?».

### 4.5 Оценка вакансии (LLM)
Для каждой прошедшей фильтр вакансии:
- **шанс в процентах** + короткое объяснение (это оценка, не гарантия — так и подаётся в UI);
- **совпадения** с профилем;
- **отличия / пробелы**;
- **недостающая информация** → вопросы пользователю.

### 4.6 Уведомление и действия
Карточка вакансии в Telegram-боте **и** на сайте (равноправны, состояние общее):
- название, компания, локация (+ расстояние), зарплата или «?», источник, ссылка;
- шанс %, совпадения, отличия;
- кнопки **«Откликнуться»**, **«Отредактировать»**, **«Пропустить»**.

### 4.7 Пакет отклика
- «Откликнуться» → генерация мотивационного письма (формат DIN 5008) и мягкая адаптация CV.
- Показывается **diff** изменений резюме.
- Пользователь получает **PDF письма + PDF CV + ссылку на вакансию** (или готовый mailto-черновик, если в вакансии есть email). Отправляет сам.
- Статус вакансии → «откликнулся», история сохраняется.
- «Отредактировать» → правка текста вручную или инструкцией («короче», «формальнее»), повторная генерация.

### 4.8 Лимиты LLM (видимо пользователю)
- Дневные потолки вызовов отдельно на оценки и на письма.
- При исчерпании лимита подписки — **одно** сообщение в Telegram «лимит, продолжу позже»; вакансии копятся в очереди и оцениваются после сброса.

## 5. Правило правды (жёсткое)

- Письмо и адаптированное резюме опираются **только на факты профиля**.
- Разрешено: переупорядочить, переформулировать, выделить релевантное, сократить нерелевантное.
- Запрещено: добавлять навыки, опыт, должности, даты, сертификаты, уровни языков, которых нет в профиле.
- Каждое изменение видно в diff. Если для сильного письма не хватает факта — сервис **спрашивает**, а не придумывает.

## 6. После MVP

- **Автоотклик** только там, где это честно: email и формы ATS (Greenhouse, Lever, Personio и т.п.). На Indeed / LinkedIn / StepStone — нет публичного API для откликов, автоматизация грозит баном → там только готовый пакет + ссылка.
- **AI-ревью Lebenslauf**: оценка качества, предложения улучшений, применение по выбору пользователя.
- **Фриланс-биржи**: самые свежие заказы с малым числом откликов и максимальным совпадением.
- Новые сайты-источники (оценка ToS и стабильности перед каждым).
- Открытие для других: API-провайдер LLM, биллинг, DPA, Impressum, Datenschutzerklärung.
- Notion как зеркало бэклога и роадмапа (источник правды — репозиторий).

## 7. Вне скоупа (MVP)

- Автоматическая отправка откликов.
- Вход в аккаунты пользователя на job-сайтах.
- Приватные Telegram-каналы и чаты.
- Мобильное приложение.
- Дизайн UI — делает владелец отдельно; здесь фиксируются только флоу.

## 8. Основные флоу

**Онбординг:** регистрация → согласие → загрузка Lebenslauf → разбор → проверка/правка профиля → ответы на вопросы по пробелам → настройки поиска (роли, локация + радиус, языки, зарплата) → выбор источников → привязка Telegram.

**Поток вакансий:** источник → нормализация → дедупликация → префильтр → очередь оценки → оценка LLM → карточка в боте и на сайте.

**Отклик:** «Откликнуться» → генерация письма + адаптация CV → diff → (правка) → PDF + ссылка/mailto → пользователь отправляет → отметка «откликнулся».

**Пропуск:** «Пропустить» → статус skipped (опционально причина — используется для улучшения фильтров).

**Лимит:** ошибка лимита → пауза → одно уведомление → очередь копится → после сброса обработка продолжается автоматически.

## 9. GDPR

- Хостинг в ЕС (сейчас — локально на Mac владельца, далее VPS Hetzner).
- Явное версионированное согласие на обработку при регистрации.
- Экспорт всех данных пользователя и **полное удаление** по запросу (включая файлы и сгенерированные документы).
- Шифрование чувствительных полей (контакты, содержимое резюме, документы).
- Ограниченный срок хранения вакансий и логов.
- **Передача данных в LLM:** текст резюме обрабатывается Anthropic (США). Для владельца это его собственный выбор. Для других пользователей — только через API с DPA и с явным пунктом в Datenschutzerklärung.
