ЦЕЛЬ
Сервис, который помогает искать работу: находит подходящие вакансии, оценивает совпадение с моим резюме, пишет письмо и слегка адаптирует резюме под вакансию, а я одним нажатием откликаюсь. Сначала делаю для себя (я единственный пользователь), позже, возможно, открою для других с дешёвой подпиской (около 5-10 евро в месяц). Рынок: Германия, Lebenslauf и письма на немецком (уточни у меня язык и сферу).

ФУНКЦИИ MVP
1. Сайт с личным аккаунтом: профиль, загрузка данных и Lebenslauf, разбор резюме в структурированный профиль.
2. Источники вакансий: предлагаемые сервисом и добавляемые мной вручную публичные Telegram-каналы. Бот постоянно сканирует их.
3. Для каждой найденной вакансии: оценка шанса (в процентах, с объяснением), точки совпадения с моим резюме и отличия.
4. Генерация мотивационного письма под вакансию и мягкая адаптация резюме под неё. Только в рамках правды, без выдуманных навыков и опыта. Показывать diff изменений.
5. Уведомления в Telegram-бот: карточка вакансии, оценка, совпадения и отличия, кнопки «Откликнуться», «Отредактировать», «Пропустить». Все то же самое должно быть доступно и на сайте. Бот и сайт равноправны.
6. Дешёвая фильтрация без нейросети (ключевые слова, язык, локация, зарплата) перед вызовом LLM.

ПОСЛЕ MVP
- Автоотклик там, где это технически и юридически честно: по email и через формы ATS (Greenhouse, Lever, Personio и т.п.). На Indeed, LinkedIn, StepStone публичного API для откликов нет, автоматизация грозит баном аккаунта. Там бот готовит полный пакет, а я открываю ссылку и отправляю сам.
- Оценка качества Lebenslauf нейросетью, предложения улучшений, применение по желанию пользователя.
- Фриланс-биржи: искать самые свежие заказы с малым числом откликов, которые лучше всего подходят мне (где выше шанс получить).
- Парсинг сайтов вакансий. Оцени риски по ToS и стабильности.

ЖЁСТКИЕ ПРАВИЛА ПО ДЕНЬГАМ
- Я не хочу ничего доплачивать. LLM работает только через мою подписку Claude Pro (Claude Code под моим логином), без API-ключа. При запуске сервис должен принудительно сбрасывать ANTHROPIC_API_KEY.
- Нужен отсекатель: при ошибке лимита сервис ставит флаг «пауза до сброса», перестаёт вызывать Claude, один раз пишет в Telegram «лимит, продолжу позже», а найденные вакансии копит в очереди и оценивает потом.
- Свой дневной потолок вызовов (отдельно на оценки и на письма), чтобы не выбирать лимит подписки.
- В архитектуре сделать абстракцию «LLM-провайдер»: сейчас Claude Code на подписке, позже можно переключить на API-ключ, если открою сервис другим. Через мою подписку обслуживать других пользователей нельзя.
- Остальные расходы минимальны: хостинг в ЕС (VPS около 5 евро или пока мой компьютер), бесплатный Telegram-бот. Чтение каналов через мой аккаунт (например, Telethon) без агрессивного опроса.
